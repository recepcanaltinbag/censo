# Data inventory

Every input under `Data/`, described. **`Data/` is read-only** — nothing in it is ever modified.
All generated artefacts live under `derived/` and are rebuilt by scripts.

> Named `derived/`, not `data/`: macOS is case-insensitive by default, so `Data/` and `data/`
> are the *same* directory. An earlier layout wrote generated files into the originals folder.

---

## 1. Campaign measurements — the primary dataset

`Data/Sampling/Sampling/{November,February,May,August}_Sampling-2018_*.xlsx`

Four workbooks, identical layout, sheet **`Analizler`** (299 rows × 87 columns).

> **Naming caveat.** All four filenames carry a 2018 export date, but the in-sheet `Tarih` row shows
> the actual sampling dates: **Nov 2017, Feb 2018, May 2018, Aug 2017/2018**. The in-sheet date is
> authoritative. Resolve the August year before writing the Materials section.

**Layout**

| Row | Content |
|---|---|
| 1 | header: `Parametre`, `Birim`, then station IDs `1 … 84`, then aggregate columns |
| 2–6 | `Enlem` (lat, DMS), `Boylam` (lon, DMS), `Yükseklik` (m), `Tarih`, `Zaman` |
| 7 | section header `Konvansiyonel` |
| 8–20 | pH, Sıcaklık, Renk, TOK, KOİ, NH3-N, NO3, NO2, Cl, F, Br, SO4, PO4 |
| 22 | section header `Toksisite` |
| 23–24 | EC50-5 min, EC50-15 min (dilution factor) |
| 26 | section header `Debi` |
| 27–28 | **`Yabataş`** (m³/s, 75 stations), **`Ekoton`** (m³/s, 38 stations) |
| 30 | section header `Metals` |
| 31–48 | As, Ba, Be, Zn, Cr, V, Co, Al, Cu, Pb, Ni, Cd, Ag, B, Sn, Ti, Sb, Hg (µg/L) |
| 50 | section header `Mikrokirleticiler` |
| 51–272 | 222 micropollutants (µg/L) |
| 274 | `COUNT` (spreadsheet bookkeeping — skipped) |

**Extracted totals** (`scripts/01_extract_campaigns.py`)

| | |
|---|---|
| Campaigns | 4 |
| Stations with data | **75** |
| Parameters | 258 (222 micropollutant · 18 metal · 14 conventional · 2 toxicity · 2 flow) |
| Measurements | **76,651** |

**Critical property — censoring is not encoded.**
No cell contains `<LOD`, `n.d.` or any qualifier. Non-detects have been replaced by `0.0`:

| Group | measurements | recorded `0.0` | share |
|---|---|---|---|
| micropollutant | 66,600 | 56,768 | **85.2%** |
| metal | 5,175 | 1,063 | 20.5% |
| conventional | 3,900 | 345 | 8.8% |
| **chemical total** | **75,675** | **58,176** | **76.9%** |

This is the paper's motivating defect. See [`03-concept.md`](03-concept.md) and
[`../eval/gate_check.md`](../eval/gate_check.md).

**Known data errors**
- November, station 2: latitude `41°61'25.5"` — 61 arc-minutes is invalid. The other three
  campaigns give `41°05'24.5"` for the same station.
- Be and Sb: negative concentrations reported (physically impossible).
- 48 analytes report positive values below their own LOQ.

## 3. Regulatory thresholds

`Data/CKS_FEnCY.xlsx`, sheet `CKS` — 153 substances.

| Column | Meaning |
|---|---|
| `Kirletici Adı` | substance name |
| `YO-ÇKS Nehirler/Göller (µg/L)` | annual-average EQS, rivers/lakes |
| `MAK-ÇKS Nehirler/Göller (µg/L)` | maximum-allowable EQS, rivers/lakes |

ÇKS = *Çevresel Kalite Standardı*, the Turkish transposition of the EU-WFD environmental quality
standards (Directive 2008/105/EC), enacted as *Yerüstü Su Kalitesi Yönetmeliği* (RG 28483, 2012).

Values carry non-breaking spaces (`\xa0`) — normalise before parsing.

## 4. Ecotoxicity

`Data/Toxicity_Ecosar_FINAL-2018_03_12.xlsx`, sheet `Batch Output` — 1,332 rows.

`CAS · Chemical · SMILES · ECOSAR Class · Organism · Duration · End Point · Concentration (µg/L) · Max Log Kow · Flags`

- 222 unique chemicals
- 3 organisms: Fish, Daphnid, Green Algae
- 3 endpoints: LC50, EC50, ChV
- Durations: 96 h (fish, algae), 48 h (daphnid)
- 42 ECOSAR structural classes

Generated by US EPA ECOSAR (QSAR prediction, not measured toxicity) — state this explicitly in
Limitations. Feeds `PNEC = min(ChV_fish, ChV_daphnid, ChV_algae) / AF`.

# Regulation packages

Generated by `scripts/19_build_regulation_packages.py`.

The paper claims regulations are pluggable, versioned packages. These are the packages. Each imports the vocabulary and contributes **individuals only** -- no class, no property -- which is what makes it safe to load one in place of another and to hold both answers at once.

| package | analytes | AA thresholds | MAC thresholds | file |
|---|---|---|---|---|
| `tr-ysky-2016` | 217 | 217 | 217 | `ontology/reg/tr-ysky-2016.ttl` |
| `eu-2008-105-2026` | 59 | 56 | 43 | `ontology/reg/eu-2008-105-2026.ttl` |

Every threshold carries `cereg:transcriptionStatus cereg:VerifiedAgainstPrimarySource`, because both sources are parsed from the legal PDFs. The project's working spreadsheet is deliberately not emitted: seven of its ten metal values, and a further eleven organics, disagree with the law.

## Using a different jurisdiction

```bash
# assess the same observations under the Turkish package
python scripts/17_run_competency_questions.py \
    --abox derived/abox/censo-waterbase.ttl
```
Load `ontology/reg/tr-ysky-2016.ttl` or `ontology/reg/eu-2008-105-2026.ttl` alongside the ABox. The thresholds carry different IRIs and different `censo:definedBy` links, so both assessments can coexist in one graph.

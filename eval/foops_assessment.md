## Reading

Two kinds of failure sit in the table above and they are not equivalent. **Missing annotations** — a citation, a publisher, an issue date, a DOI — are properties of the file and can be added without changing a single axiom. **Registry absence** is a property of the wider ecosystem: the ontology is not indexed in a public registry, which no edit to the file achieves and which is why the metadata-when-the-ontology-is-gone check fails with it.

Nothing in the assessment bears on the modelling claims of the paper. It is reported because a reader asked to reuse an ontology is entitled to know what reuse currently costs.

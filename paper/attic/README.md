# Retired front-ends

`main.tex` (article class) and its generated single-file view were the generic
manuscript before the target narrowed to Elsevier. They are kept here rather
than deleted because `paper/` is not under version control, so a deletion would
be unrecoverable.

Nothing builds from this directory. The live front-end is
`paper/main-elsevier.tex`; the file to upload is
`paper/main-elsevier-standalone.tex`, generated by
`scripts/96_flatten_paper.py`.

One difference worth knowing if these are ever revived: `main.tex` embedded
`fig01_graphical_abstract.pdf` in the body. The Elsevier front-end does not,
because Elsevier takes the graphical abstract as a separate upload.

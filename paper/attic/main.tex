\section*{Data and code availability}
The ontology, the processing pipeline, every query and all evaluation outputs
are archived at \pending{Zenodo DOI}. The ontology and both regulation
packages are published under \url{https://w3id.org/censo/} (CC~BY~4.0); code
under MIT. The measurements are the EEA's Waterbase --- Water Quality ICM,
aggregated release, which is openly downloadable, so every figure and every
number in this paper can be re-derived without applying to anyone for
access.

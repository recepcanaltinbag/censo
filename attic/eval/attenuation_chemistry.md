# Does the chemistry agree with the mass balance?

Generated by `scripts/21_attenuation_chemistry.py`.

The split in `eval/mass_balance.md` uses only hydrology and arithmetic: no chemical property enters it. Chemistry is therefore an independent check. Substances genuinely removed from river water are removed by sorption, which rises with hydrophobicity, and by biodegradation. If the split detects real behaviour, the substances needing attenuation should be more hydrophobic and less soluble.

The unit of analysis is the **substance**, not the comparison: one substance contributes many reach-campaign comparisons that share its chemistry, and testing over those would inflate the sample and manufacture significance.

With 35 substances the test is weak, so this is not evidence of absence -- but it is not support either, and the classification should be read as hydrological bookkeeping rather than as evidence about mechanism. We report it because a test run only when it succeeds is not a test.

## Limits

- log P and solubility are the vendor's reported values, not measured in this study.
- Sorption depends on suspended solids and organic carbon, neither of which was measured, so hydrophobicity is a proxy for the mechanism, not a model of it.
- 35 substances is a small sample; only a strong effect would be detectable.
